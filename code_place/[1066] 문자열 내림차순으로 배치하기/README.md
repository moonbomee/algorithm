### 문제 설명
<p>문자열 s에 나타나는 문자를 큰 것부터 작은 순으로 정렬해 새로운 문자열을 출력하시오.</p>

### 입력
<p>문자열 s는 영문 대소문자로만 구성되어 있으며, 대문자는 소문자보다 작은 것으로 간주합니다.</p><p>입력되는 문자열 s의 길이는 1이상입니다.</p>

### 출력
<p>주어진 문자열을 내림차순으로 정렬한 후 출력하시오.</p>

### 예제 입력/출력
**예제 입력 1**
```
Zbcdefg
```
**예제 출력 1**
```
gfedcbZ
```
